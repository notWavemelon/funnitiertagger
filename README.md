# funnitiers
this is a little mod for my friend group and the tier list it's based off

[funnitiers](https://funnitiers.onrender.com) is a minecraft pvp tier list that takes minecraft pvp was less seriously
## features
- show ranks next to names
![tiers next to names](https://cdn.modrinth.com/data/YEIMhFBJ/images/375d5b1e19d07e6b9a07bf246da39f7e2871e424.png)
- search other players
  ![example profile screenshot of me](https://cdn.modrinth.com/data/YEIMhFBJ/images/e048741944cbef41cd8dc1de9a2c815cde531373.png)
## commands
- /funnitiers|funnitiertagger
    - opens config
- /funnitiers|funnitiertagger <player>
    - queries the tiers of a uuid/playername
- /funnitiertagger:clearcache
    - self explanatory
- /funnimode <gamemode>
    - lets you pick what gamemode to display/prioritize | also clears cache
